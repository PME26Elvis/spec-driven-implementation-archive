# Repomix authored-corpus review

Measured project: `project/0820-sudoku-workbuddy_curated`

This config measures the normalized **implementer-authored corpus**, not the full archived run evidence.

The embedded benchmark task pack is not present in the curated Git project: it was verified byte-for-byte against the canonical `specs/c17-win32-sudoku/` tree and is preserved in the complete raw Release ZIP instead.

Reviewed Repomix exclusions from the 105-file curated project:

- `results/**` — 32 generated validation, audit, locstat, test, and completion evidence files; useful to archive, but not implementation source.
- `include/ui/sdk_ui_font_data.h` — auto-generated 5×7 bitmap font table. The file itself states that it is generated by `build/vault_test/genfont.py`.
- `src/ui/sdk_ui_font_data.h` — duplicate auto-generated font table used by the source tree.

Everything else in the curated project is retained in the normalized metric, including C source/headers, tests, developer tools, build/test scripts, configuration, documentation, and the authored generator/helper scripts preserved from `build/`.

The curated project contains **105 files**. These reviewed exclusions remove 34 generated evidence/font files, leaving **71 authored files**. `Count authored run tokens` workflow run 3 validated this exact selection with Repomix 1.18.0 and `o200k_base`: **218,463 tokens**.
