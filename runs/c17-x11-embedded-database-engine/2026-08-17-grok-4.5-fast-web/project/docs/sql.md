# SQL surface (implemented)

CREATE/DROP TABLE, CREATE INDEX, INSERT (multi-row), SELECT, WHERE (= != < > <= >= IN BETWEEN LIKE IS NULL),
scalar and correlated subquery (`@col`), ORDER BY, LIMIT/OFFSET, COUNT/SUM/AVG/MIN/MAX,
GROUP BY/HAVING, JOIN/LEFT JOIN, UPDATE, DELETE, BEGIN/COMMIT/ROLLBACK, VACUUM, EXPLAIN, ANALYZE.

Not a full SQL standard implementation.
